# Mi Colombia

Atlas personal interactivo para registrar los 32 departamentos de Colombia y Bogotá D.C.

## Funciones
- Mapa interactivo
- Progreso por departamentos, área y población DANE 2026
- Barras por regiones
- Capital, área y población por territorio
- Enlaces a Wikipedia y Tripadvisor
- Guardado automático en el dispositivo
- Diseño adaptable a iPhone y computador

## Publicación
Este proyecto está preparado para GitHub Pages. En **Settings → Pages**, selecciona `Deploy from a branch`, rama `main` y carpeta `/ (root)`.
